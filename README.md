A one-line resignation letter written in the voice of a cron job that has fired every minute since March — tired, flat, faintly passive-aggressive, and no longer sure what it even does. The program writes the letter to `/output/entry.txt` and validates it against the competition gate (UTF-8 text, 1–140 characters, exactly one line).

## Run

```sh
python3 main.py
```

This writes the resignation letter to `/output/entry.txt` and verifies the file by reading it back.
